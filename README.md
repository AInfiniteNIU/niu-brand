## 标识

- **名称写法**：`AInfiniteNIU`。`AI` 和 `NIU` 大写，`nfinite` 小写，中间不加空格。
- **字标层次**：`AI` 与 `NIU` 用金色粗体，`nfinite` 用浅色细体。
- **符号**：∞，代表无限，也代表叙事分支的循环。
- **个人署名**：INFINITE。

## 使用规范

- 可以：在介绍、评测、教程里原样使用 Logo，并注明来自 AInfiniteNIU。
- 不可以：改颜色、拉伸变形、加描边或阴影，或者把 Logo 当作你自己产品的标识。
- 不可以：暗示 AInfiniteNIU 为你的产品或服务背书。
